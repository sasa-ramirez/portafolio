Kódea

La plataforma de tutoría académica de la Universidad de La Guajira. Tutores crean cursos, tareas y materiales; estudiantes resuelven desde el celular; coordinación ve y administra todo. Empezó para programación y hoy sirve para cualquier materia.

plataforma-tutoria.vercel.app
120+commits en el repositorio
3roles: estudiante, tutor y coordinador
4tipos de ejercicio, calificados con IA
3lenguajes que se ejecutan en el navegador

Lo que hace

  • Editor que ejecuta PSeInt (con un intérprete propio), Python y Java.
  • Quiz en vivo con QR y modo examen que registra los cambios de pestaña.
  • Informes y actas oficiales en Word, listos para firmar.
  • Notificaciones push, incluso con el celular cerrado.

Decisiones técnicas

  • Row Level Security de Postgres: la seguridad vive en la base de datos.
  • La IA se llama desde Edge Functions; la API key nunca llega al navegador.
  • Plazos de entrega validados también en el servidor.
  • Pruebas en cada push y respaldo diario cifrado con GitHub Actions.
