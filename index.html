Proyecto principal

Kódea

En producción

Plataforma de tutoría académica para la Universidad de La Guajira.

Qué es

Kódea reúne en una sola app las tutorías académicas de la universidad: los tutores crean cursos, tareas y materiales; los estudiantes resuelven y estudian desde el celular, y coordinación ve y administra todos los cursos. Empezó para programación y hoy sirve para cualquier materia.

Lo que hace

  • Tareas de código, opción múltiple, numéricas y abiertas, calificadas con IA y revisadas por el tutor.
  • Editor en el navegador que ejecuta PSeInt (con un intérprete propio), Python y Java.
  • Quiz en vivo con código QR y modo examen que registra los cambios de pestaña.
  • Genera informes y actas oficiales en Word, listos para firmar.

Decisiones técnicas

  • Seguridad en la base de datos con Row Level Security de Postgres, no solo en el frontend.
  • La IA se llama desde Edge Functions, así la API key nunca llega al navegador.
  • Plazos de entrega validados también en el servidor.
  • Pruebas en cada push y respaldo diario cifrado con GitHub Actions.
